页面布局基础

在这个练习中，我们使用 CSS Grid 创建了一个复杂的页面布局。这种布局在现代网站中非常常见，包含了头部、侧边栏、主内容区域、辅助内容和底部。

布局特点

  • 头部和底部跨越整个页面宽度
  • 中间区域分为三列：侧边栏、主内容、辅助内容
  • 在小屏幕上自动变为单列布局
  • 使用 Grid 的 grid-template-areas 让布局更直观

这样的布局为我们提供了很大的灵活性，可以轻松调整各个区域的大小和位置。
